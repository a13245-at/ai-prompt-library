# ai-prompt-library

A collection of tested prompt templates for students and office work.

一套給大學生和日常辦公用的 Prompt 模板庫。**每個模板都經過對照測試**，不是網上抄來就用，測試過程和已知限制都寫在模板檔案裡。

## 模板目錄

| 模板 | 用途 | 版本 | 狀態 |
|---|---|---|---|
| [週報整理](templates/office/weekly-report.md) | 把零散記錄整理成固定四段的週報 | v1 | 已通過對照測試 |
| [課文摘要](templates/study/summary.md) | 課文整理成重點與「錯誤／正確」易錯概念 | v1.1 | 已通過越界與壓力測試 |
| [郵件撰寫](templates/writing/email.md) | 把要點寫成給老師或長輩的得體郵件 | v1.1 | 已通過缺口測試，有已知限制 |

## 怎麼用

1. 點進想用的模板，複製 **Prompt** 框裡的內容
2. 把括號裡的說明換成你自己的資料
3. 貼給任何 AI（ChatGPT、豆包、智譜、Claude 等）
4. 用模板裡的「輸出檢查清單」核對結果，**不要盲信輸出**

## 每個模板的固定結構

- **用途與適用情境**：什麼時候用
- **Prompt**：含角色、格式、規則，可直接複製
- **輸出檢查清單**：用來驗證 AI 有沒有照做
- **測試記錄**：測過哪些平台、發現什麼問題、怎麼改
- **測試用假資料**：任何人都能重跑同樣的測試

## 我怎麼測試模板

每個模板走同一個循環：

1. 先寫簡單版（v0），用假資料跑
2. 對照檢查清單，找出問題（例如編造內容、格式飄移、結尾推銷）
3. 把問題寫成明確規則，加進 Prompt
4. 重跑驗證，再加壓力測試（例如只給一句話、故意缺資訊）
5. 記錄結果與已知限制

### 目前得到的幾個結論

- AI 只讀得到你貼進對話的內容，沒貼等於不存在
- 指令寫了才有，沒寫就沒有；想要穩定格式，就把格式寫進 Prompt
- 不同平台的穩定度不同，要自己測，不能假設
- 「正確的越界」仍是越界：AI 補充課文外的知識，即使是對的，也無法讓人確認是否可信
- 規則要具體：「不要編造」效果有限，「不要替我加『我會…』之類的承諾」更有效

## 已知限制

- 測試以豆包、智譜為主，各平台測試次數不均
- 單次結果有隨機性，結論僅代表目前的測試樣本
- 模板無法保證 AI 輸出一定正確，重要內容（如正式郵件、成績相關內容）請自行核對

## 使用須知

- 不要在 Prompt 裡填入真實的密碼、身分證號、學號、客戶資料等敏感資訊
- 使用 AI 輔助作業或寫作時，請遵守所在學校的規定
- 本庫的測試假資料皆為虛構
