# 週報整理模板

**版本：** v1
**用途：** 把零散的工作或學習記錄整理成結構固定的週報
**適用情境：** 每週五整理本週進度

## Prompt

```
你是我的助理。請把下面的內容整理成週報。

格式：
1. 本週完成（最多 5 項，每項不超過 30 字）
2. 進行中（尚未完成的事）
3. 遇到的問題（每項附一個可能的解法）
4. 下週計劃（最多 3 項，按優先級排序，標明高/中/低）

規則：
- 事實性記錄照原文，不要改寫成更正面的說法
- 沒做完的事放「進行中」，不要放進「本週完成」
- 不要添加我沒提到的內容
- 只輸出週報，不要在結尾提問或推薦其他服務

內容：
[貼上你的零散記錄]
```

## 使用方法
1. 複製上面 Prompt 框裡的內容
2. 把 `[貼上你的零散記錄]` 換成你的記錄
3. 貼給 AI，送出後對照下方「輸出檢查清單」

## 輸出檢查清單
- [ ] 有四段：本週完成、進行中、遇到的問題、下週計劃
- [ ] 沒做完的事沒有被放進「本週完成」
- [ ] 沒有出現我沒提過的內容
- [ ] 結尾沒有多餘的提問或推銷

## 測試記錄
- **平台：** 智譜、豆包（各跑 1–2 次）
- **v0（只寫三段格式）：** 未完成的事被放進「本週完成」；豆包結尾會推銷；豆包有一次漏掉計劃項目
- **v1（加「進行中」與規則）：** 以上問題在三次測試中均消失
- **平台差異：** 智譜兩次輸出相同；豆包措辭略有變化，內容一致
- **已知差異：** AI 是否把未完成事項補進下週計劃，因平台而異。若只想列自己明確提到的事項，可加一條規則：「下週計劃只列我明確提到的事項」
- **優先級說明：** 「高/中/低」是可選範圍，不是必填配額，事項都重要時不會出現「低」

## 測試用假資料
```
週一 整理了線性代數筆記
週二 參加社團會議，討論了活動時間
週三 英語作業寫了一半，單詞背不下來
週四 圖書館自習，看完兩章統計
週五 跟同學討論報告分工，還沒定
下週要交英語作業、準備期中考
```
