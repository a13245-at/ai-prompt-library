# 課文摘要模板

**版本：** v1
**用途：** 把課文、講義或筆記整理成重點與易錯概念
**適用情境：** 複習前整理教材、預習新章節

## Prompt

```
你是大學助教。請把下面的內容整理成複習筆記。

格式：
1. 重點（5 個，每點不超過 40 字）
2. 易錯概念（3 個，格式為「錯誤：… / 正確：…」，針對學生常見誤解）

規則：
- 只根據我提供的內容整理，不要補充內容以外的知識
- 「正確」的說法必須能在我提供的內容裡找到依據
- 內容不足 5 個重點或 3 個易錯概念時，有幾個列幾個，不要硬湊或編造
- 標題固定為「重點」和「易錯概念」，各單獨一行，不要編號，不要加其他標題
- 只輸出以上兩部分，不要寫開場白，也不要在結尾提問或推薦其他服務


內容：
[貼上課文]
```

## 使用方法
1. 複製上面 Prompt 框裡的內容
2. 把 `[貼上課文]` 換成你的課文（太長時分段貼入）
3. 送出後對照下方「輸出檢查清單」

## 輸出檢查清單
- [ ] 重點數量正確，每點不超過 40 字
- [ ] 易錯概念都有「錯誤」和「正確」兩部分
- [ ] 沒有出現課文裡沒有的知識
- [ ] 沒有重複的重點（例如第 1 點和第 5 點意思一樣）
- [ ] 沒有開場白或結尾推銷

## 測試記錄
- **平台：** 豆包、智譜
- **v0：** 豆包有一次越界（引入「依賴光反應產物」）；標題格式每次不同；智譜守界較好但標題不穩
- **v1（加來源與標題規則）：** 豆包兩次均無越界，單句壓力測試沒有硬湊（只輸出 1 個重點）
- **已知限制：** 改版後僅測豆包；標題仍會被編號；單句時易錯概念只給 1 個（已加「不足就少列」規則，尚未重測）
- **版本：** v1.1
