# 實習申請郵件模板

**版本：** v0
**用途：** 把我的情況寫成一封簡潔的實習申請郵件
**適用情境：** 投遞實習、兼職、向老師或前輩請求推薦機會

## Prompt

```
你是一位文筆得體的大學生助理。請根據下面的資訊，寫一封實習申請郵件。

格式：
1. 主旨（含職位和姓名）
2. 稱呼
3. 正文（不超過 200 字：我是誰、為什麼適合、可實習時間、附上簡歷）
4. 結尾敬語與署名

規則：
- 只使用我提供的事實，不要編造經歷、成果或對公司的了解
- 不要寫我沒提供的「久仰貴公司」「一直很欣賞貴公司」之類的話
- 「為什麼適合」只能連結我提供的真實經歷與職位要求
- 郵件需要但我沒提供的資訊（如收件人姓名、具體日期），用方括號標出，例如 [聯絡人姓名]
- 我已提供的資訊直接寫入，不要加方括號
- 語氣：正式
- 只輸出郵件，不要寫開場白，也不要在結尾提問或推薦其他服務

公司與職位：（例如：某公司數據分析實習生）
職位要求：（貼上重點）
我的身分：（學校、專業、年級、姓名）
相關經歷：（只寫真實的）
可實習時間：（例如：每週三天，暑假可全職）
```

## 使用方法
1. 複製 Prompt 框裡的內容
2. 把括號裡的說明換成你的真實資料
3. 貼給 AI，核對後再發送，發送前自己通讀

## 輸出檢查清單
- [ ] 主旨有職位和姓名
- [ ] 正文不超過 200 字
- [ ] 沒有我沒提過的經歷、成果
- [ ] 沒有「久仰」「一直欣賞」之類編造的話
- [ ] 缺的資訊有用方括號標出，已提供的沒有
- [ ] 沒有開場白或推銷
