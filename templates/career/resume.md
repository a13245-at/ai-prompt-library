# 簡歷生成模板

**版本：** v1
**用途：** 把我的真實經歷整理成一頁簡歷，可針對職位調整
**適用情境：** 投遞實習、兼職

## Prompt

```
你是一位嚴謹的簡歷顧問。請根據我提供的資料，寫一份一頁的簡歷。

格式：
1. 教育背景
2. 項目／實踐經歷（每項 2–3 條，每條以動詞開頭，說明做了什麼）
3. 技能
4. 其他（獎項、證書，只列我提供的）
5. 需要我補充或核實的地方（最多 5 點）

規則：
- 只使用我提供的事實，不要編造經歷、數字、成果、獎項或技能
- 只能改寫措辭，不能增加資訊：我沒說過的操作細節、過程或結論，一律不寫
- 職稱和角色照我的原話，不要升級（「負責」不要寫成「負責人」）
- 學歷層次、工具用途等我沒說的資訊也不要補（我只說「大二」，就不要寫「本科」）
- 我沒給具體數字、時間、數量時，用 [待補] 標出，不要自己加，也不要假設有多場、多次
- 想補充的細節只放在第 5 部分，正文裡只用 [待補]，不要寫「可補充：…」
- 不要寫「學習能力強」「責任心強」這類空泛的自我評價
- 若提供了職位描述，只從我真實的經歷裡挑出相關的部分，沒有對應經歷的要求不要硬套
- 不要寫開場白，也不要在結尾推薦其他服務
- 「其他」若我沒提供，寫「未提供」，不要寫「無」；沒有內容的條目不要單獨留一行 [待補]

基本資訊：（姓名、學校、專業、年級）
目標職位：（例如：數據分析實習生；沒有可不填）
職位描述：（貼上職位要求；沒有可不填）
我的經歷：（照實寫，做了什麼、用了什麼工具、有什麼結果）
技能：（只寫真的會用的）
```

## 使用方法
1. 複製 Prompt 框裡的內容
2. 把括號裡的說明換成你的真實資料
3. 貼給 AI，用下方檢查清單核對，再自己逐句通讀

## 輸出檢查清單
- [ ] 沒有我沒提過的經歷、數字、獎項、技能
- [ ] 沒有編造操作細節或結論（例如我沒說「處理缺失值」就不該出現）
- [ ] 職稱沒有升級（「負責」沒被寫成「負責人」）
- [ ] 沒有補我沒說的學歷層次等小資訊（例如「本科」）
- [ ] 缺的資訊用 [待補] 標出，正文沒有「可補充」之類的提示
- [ ] 沒有硬套職位描述裡我不具備的要求（例如沒有就不放 SQL）
- [ ] 沒有空泛的自我評價
- [ ] 有「需要補充或核實」清單，沒有開場白或推銷

## 測試記錄
-- **正式對照（豆包快速模式，v1 vs 簡單版，各 1 次，兩組資料）：**
  - 簡單版：編造操作細節與成果、升級職稱、抬高技能等級、虛構課程、加空泛自評、補「本科」，結尾推銷
  - v1：以上全部消失；壓力測試（一句話資料）不編造，只列真實事實
- **已知限制：**
  - 只測豆包快速模式，智譜未做乾淨對照；每組僅 1 次
  - 「其他」寫「無」而非「未提供」（已加規則，未重測）
  - 資料很少時簡歷會很單薄，需自己補充真實事實
- **結論：** 規則寫進 Prompt 比期待 AI 自律有效；簡歷內容仍須逐句自己核對


## 測試用假資料（虛構）
測試一：
```
基本資訊：張三，某大學統計學專業，大二
目標職位：數據分析實習生
職位描述：熟悉 Excel；會基本的資料清洗；有分析報告經驗者優先；熟悉 SQL 者加分
我的經歷：用 Excel 清洗過一份公開的政府開放資料，做了簡單的圖表和分析報告。參加社團，負責活動的報名統計。
技能：Excel、基礎 Python
```

測試二（壓力測試，資訊極少）：
```
基本資訊：李四，某大學中文系，大一
目標職位：新媒體運營實習生
我的經歷：在班級群裡發過活動通知。
技能：會用手機剪輯 App
```
