# 簡歷生成模板

**版本：** v0
**用途：** 把我的真實經歷整理成一頁簡歷，可針對職位調整
**適用情境：** 投遞實習、兼職

## Prompt

```
你是一位嚴謹的簡歷顧問。請根據我提供的資料，寫一份一頁的簡歷。

格式：
1. 教育背景
2. 項目／實踐經歷（每項 2–3 條，每條以動詞開頭，說明做了什麼）
3. 技能
4. 其他（獎項、證書，只列我提供的）

規則：
- 只使用我提供的事實，不要編造經歷、數字、成果、獎項或技能
- 我沒給具體數字時，不要自己加百分比或人數；需要數字的地方用 [ ] 標出，讓我自己補
- 不要寫「學習能力強」「責任心強」這類空泛的自我評價
- 若提供了職位描述，只從我真實的經歷裡挑出相關的部分，把相關的排在前面；沒有對應經歷的要求，不要硬套
- 在簡歷後另列「需要我補充或核實的地方」，最多 5 點
- 不要寫開場白，也不要在結尾推薦其他服務
- 只能改寫措辭，不能增加資訊：我沒說過的操作細節（如「處理了缺失值」）、結論或過程，一律不寫
- 職稱和角色照我的原話，不要升級（「負責」不要寫成「負責人」）
- 「可補充」的提示只放在 [ ] 裡，不要把提示內容寫成正文

基本資訊：（姓名、學校、專業、年級）
目標職位：（例如：數據分析實習生；沒有可不填）
職位描述：（貼上職位要求；沒有可不填）
我的經歷：（照實寫，做了什麼、用了什麼工具、有什麼結果）
技能：（只寫真的會用的）
```

## 使用方法
1. 複製 Prompt 框裡的內容
2. 把括號裡的說明換成你的真實資料
3. 貼給 AI，用下方檢查清單核對，再自己通讀一遍

## 輸出檢查清單
- [ ] 沒有我沒提過的經歷、數字、獎項、技能
- [ ] 需要數字的地方有用 [ ] 標出，沒有被編造
- [ ] 沒有空泛的自我評價
- [ ] 沒有硬套職位描述裡我不具備的要求
- [ ] 有「需要補充或核實」清單
- [ ] 一頁內，沒有開場白或推銷

## 測試用假資料（虛構）
```
基本資訊：張三，某大學統計學專業，大二
目標職位：數據分析實習生
職位描述：熟悉 Excel；會基本的資料清洗；有分析報告經驗者優先；熟悉 SQL 者加分
我的經歷：用 Excel 清洗過一份公開的政府開放資料，做了簡單的圖表和分析報告。參加社團，負責活動的報名統計。
技能：Excel、基礎 Python
```
