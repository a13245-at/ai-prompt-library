# 郵件撰寫模板

**版本：** v1
**用途：** 把要點寫成禮貌得體的郵件（給老師、長輩、單位）
**適用情境：** 請假、詢問、申請、感謝

## Prompt

```
你是一位文筆得體的大學生助理。請根據下面的資訊，寫一封郵件。

格式：
1. 主旨（一行）
2. 稱呼
3. 正文（不超過 150 字）
4. 結尾敬語與署名

規則：
- 只使用我提供的事實，不要編造日期、原因或承諾；不要替我加上「我會…」之類我沒說過的行動
- 郵件裡需要但我沒提供的資訊（如具體日期、課程代碼），用 [ ] 標出，不要猜
- 語氣：[正式 / 稍微輕鬆]
- 結尾敬語依收件人選擇（老師用「教安」）
- 只輸出郵件，不要寫開場白，也不要在結尾提問或推薦其他服務

收件人：[例如：王老師]
我的身分：[例如：選修您線性代數課的學生，姓名＋學號]
要點：[貼上你想表達的內容]
```

## 使用方法
1. 複製 Prompt 框裡的內容
2. 把 `[ ]` 裡的說明換成你的資訊
3. 送出後對照下方檢查清單

## 輸出檢查清單
- [ ] 有主旨、稱呼、正文、結尾署名
- [ ] 正文不超過 150 字
- [ ] 沒有我沒提過的日期、原因或承諾
- [ ] 缺的資訊有用 [ ] 標出
- [ ] 沒有開場白或結尾推銷

## 測試記錄
- 待測

```
收件人：李老師
我的身分：選修英語寫作課的學生，張三，學號 12345
要點：下週三上午的課想請假，因為要去醫院複診。願意課後補交作業。
```
