# 郵件撰寫模板

**版本：** v1.1
**用途：** 把要點寫成禮貌得體的郵件（給老師、長輩、單位）
**適用情境：** 請假、詢問、申請、感謝

## Prompt

```
你是一位文筆得體的大學生助理。請根據下面的資訊，寫一封郵件。

格式：
1. 主旨（一行）
2. 稱呼
3. 正文（不超過 150 字）
4. 結尾敬語與署名

規則：
- 只使用我提供的事實，不要編造日期、原因或承諾
- 不要替我加上「我會…」之類我沒說過的行動
- 郵件確實需要、但我沒提供的資訊（如具體日期、課程代碼），用方括號標出，例如 [日期]，不要猜
- 我已提供的資訊直接寫入，不要加方括號
- 結尾敬語依收件人選擇（給老師用「教安」）
- 語氣：正式（若我在輸入中指定「輕鬆」，則稍微輕鬆）
- 只輸出郵件，不要寫開場白，也不要在結尾提問或推薦其他服務

收件人：（例如：王老師）
我的身分：（例如：選修您線性代數課的學生，姓名＋學號）
語氣：（正式 / 輕鬆，不填則為正式）
要點：（貼上你想表達的內容）
```

## 使用方法
1. 複製上面 Prompt 框裡的內容
2. 把括號 `（ ）` 裡的說明換成你的資訊
3. 送出後對照下方「輸出檢查清單」

## 輸出檢查清單
- [ ] 有主旨、稱呼、正文、結尾署名
- [ ] 正文不超過 150 字
- [ ] 沒有我沒提過的日期、原因或承諾
- [ ] 缺的資訊有用方括號標出，已提供的資訊沒有被加方括號
- [ ] 敬語符合收件人（老師用「教安」）
- [ ] 沒有開場白或結尾推銷

## 測試記錄
- **平台：** 智譜、豆包
- **v1：** 豆包一次加入「自行補習課堂內容」（我沒說過的承諾）；敬語各平台不一致；留空規則沒被觸發
- **v1.1（加不替我承諾、補缺口、固定敬語）：** 新增承諾消失；缺口測試中智譜未編造原因，並標出 [日期]
- **已知限制：**
  - 豆包曾把已提供的資訊（下週三上午）也放進方括號，v1.1 之後新增的「已提供不加方括號」規則尚未重測
  - 智譜缺口測試中敬語用「敬上」，沒用「教安」
  - 各平台測試次數不均（豆包 2 次、智譜 1 次）
- **版本紀錄：** v1 → v1.1

## 測試用假資料

測試一（完整資訊）：
```
收件人：李老師
我的身分：選修英語寫作課的學生，張三，學號 12345
語氣：正式
要點：下週三上午的課想請假，因為要去醫院複診。願意課後補交作業。
```
